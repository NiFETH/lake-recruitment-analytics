# lake-recruitment-analytics

## Objective

Develop an end-to-end data analytics and machine learning
pipeline for identifying young midfielders whose playing
profiles fit the tactical requirements of Como 1907.

The initial case study focuses on identifying players capable
of performing a role similar to Máximo Perrone.

## Recruitment Brief

Target position:
Defensive / Central Midfielder

Reference player:
Máximo Perrone

Target age:
≤ 23

Minimum playing time:
TBD

Key characteristics:
- Ball progression
- Progressive passing
- Possession retention
- Press resistance
- Defensive activity
- Counterpressing ability
- Ability to receive and progress from deep areas

## Planned Technical Stack

- Python
- SQL
- Google BigQuery
- StatsBomb event data
- pandas / NumPy
- scikit-learn

## Planned Pipeline

Raw Event Data
→ Data Ingestion
→ BigQuery
→ SQL Feature Engineering
→ Exploratory Data Analysis
→ Player Representation
→ Similarity / Clustering
→ Recruitment Shortlist
→ Player Reports
